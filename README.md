# Modelo para Aplicaciones Web Progresivas (PWA)

Plantilla base y arquitectura local estándar para el desarrollo de PWAs.

## Estructura
- `/public`: Archivos estáticos, iconos y capturas para el manifest.
- `/src`: Código fuente modular (CSS, JS).
- `sw.js`: Registro y lógica del Service Worker.
- `manifest.json`: Configuración de instalación y metadatos de la PWA.
- `index.html`: Punto de entrada de la aplicación.
